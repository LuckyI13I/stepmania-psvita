[How to Install Songs]
Songs are laid out based on the group that they are in.

Songs\							: root folder
	StepMania 5\				: group folder
		MechaTribe Assault\		: song/simfile folder
			*.png, *.mp3/*.ogg, *.sm/*.ssc/etc files

[Folder names]
Spaces, apostrophes and other usual characters are fine in folder names:

Songs\
	Rudy's Mix\
		Some Song\
			*.png, *.mp3/*.ogg, *.sm/*.ssc/etc files

Nothing has to be renamed or escaped - the game reads these names as-is.

[How NOT to install songs]
This is not the documented layout, but it still loads: the song folder is
picked up as its own group and the game logs a warning instead of refusing to
start:

Songs\
	Some Song\
		*.png, *.mp3/*.ogg, *.sm/*.ssc/etc files

And this won't work because StepMania doesn't handle sub-groups:

Songs\
	Song Group\
		SubGroup1\
			Some Song\
				*.png, *.mp3/*.ogg, *.sm/*.ssc/etc files
